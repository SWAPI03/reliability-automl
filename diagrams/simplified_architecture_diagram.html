Reliability-Aware AutoML System Architecture

A comprehensive system for evaluating data trustworthiness and training reliable ML models

LAYER 1: USER INTERFACE (Streamlit)
📁 File Upload
Users upload CSV datasets through Streamlit's file_uploader widget
📊 Interactive Dashboard
Real-time visualization of reliability scores, trust metrics, and model performance
📈 Charts & Metrics
Display trust distributions, score breakdowns, and comparison charts

Download trained models (.joblib) and explainability reports (.json)

LAYER 2: PIPELINE ENGINE (16 Processing Stages)

Phase 1: Data Ingestion & Validation

1 Validator
• Parse CSV file using pandas
• Detect column types (numeric, categorical, datetime)
• Identify target column using heuristics
• Validate minimum row count (≥10 rows)
2 Preprocessor
• Impute missing values (mean for numeric, mode for categorical)
• One-hot encode categorical features
• Standardize numeric features (mean=0, std=1)
• Preserve original raw data unchanged

Phase 2: Five-Dimensional Reliability Scoring

3 Structural Score (S)
• Calculate missing value ratio
• Detect duplicate rows
• Identify constant columns
• Formula: S = 1 - (0.4×missing + 0.3×duplicate + 0.3×constant)
4 Statistical Score (T)
• Detect outliers using Z-score (small datasets) or IsolationForest (large datasets)
• Identify low-variance features
• Formula: T = 1 - (0.6×outlier_ratio + 0.4×low_variance_ratio)
5 Pattern Analysis (Similarity & Conflict)
• Compute pairwise cosine similarity between rows
• Calculate Similarity Score (Sim) = mean similarity across all pairs
• Detect conflicts: identical features with different labels
• Calculate Conflict Score (C) = conflicting_pairs / total_pairs
6 Deduction Score (D)
• Cluster rows using KMeans (5 clusters)
• Assign pseudo-source trust to each cluster
• Formula: D = mean trust of cluster assignments
7 Reliability Fusion
• Combine all five scores into composite Reliability Score (R)
• Learn optimal weights using logistic regression OR use configured weights
• Formula: R = w₁S + w₂T + w₃Sim + w₄(1-C) + w₅D
• Output: R ∈ [0, 1] (higher = more reliable)

Phase 3: Trust Propagation

8 Reliability Graph
• Build graph where nodes = data rows
• Add edges between similar rows (cosine similarity > threshold)
• Edge weights = similarity values
9 Trust Propagation
• Initialize trust scores for each row using R
• Iteratively propagate trust through graph edges
• Formula: t(rᵢ) = (1 - ∏(1 - t(rⱼ)×sim(i,j))) × (1-conflict) × t(source)
• Converge when max change < 0.001 or 1000 iterations

Phase 4: Model Training & Selection

10 AutoML Trainer
• Compute sample weights: wᵢ = trust_score[i] × R
• Train 3 models with trust-weighted samples:
  → Random Forest (Classifier/Regressor)
  → Logistic/Linear Regression
  → XGBoost (Classifier/Regressor)
• Use 5-fold cross-validation with sample weights
11 Model Selection
• Classification: Score = Accuracy × R
• Regression: Score = (1 - normalized_RMSE) × R
• Select model with highest reliability-adjusted score
12 Feedback Refinement
• Compute per-row prediction errors
• Refine trust scores: trust[i] ← trust[i] × (1 - error[i])
• Re-normalize so max(trust) = 1.0

Phase 5: Feature Analysis & Explainability

13 Feature Trust
• Calculate trust score for each feature
• feature_trust[f] = mean(trust_scores for non-missing rows)
• Compute confidence score = 1 - variance(trust_scores)
14 Explainability (SHAP)
• Generate SHAP values for best model
• Calculate feature importance = mean(|SHAP values|)
• Flag features with high importance but low trust
• Provide interpretable explanations for predictions

Phase 6: Robustness Testing

15 Noise Simulation
• Add Gaussian noise to numeric features
• Retrain models on noisy data with same trust weights
• Compare performance: trust-weighted vs baseline
• Demonstrate robustness of reliability-aware approach
16 Baseline Comparison
• Train models WITHOUT trust weighting
• Compare accuracy/RMSE: reliability-aware vs standard
• Show performance improvement from trust-based training

KEY FORMULAS & METRICS

Reliability Scores

S = 1 - (0.4×missing + 0.3×dup + 0.3×const)
T = 1 - (0.6×outlier + 0.4×low_var)
Sim = mean(cosine_similarity)
C = conflicts / total_pairs
D = mean(cluster_trust)
R = w₁S + w₂T + w₃Sim + w₄(1-C) + w₅D

Trust & Model Selection

trust[i] = propagated via graph
sample_weight[i] = trust[i] × R
Classification: Score = Accuracy × R
Regression: Score = (1 - RMSE) × R
feature_trust[f] = mean(trust[non-missing])
confidence = 1 - variance(trust)
END-TO-END DATA FLOW
1. Input: User uploads CSV → Validated & preprocessed
2. Scoring: Five dimensions analyzed → Fused into Reliability Score (R)
3. Graph: Row similarity graph built → Trust propagated through network
4. Training: Models trained with trust-weighted samples → Best model selected
5. Refinement: Trust refined using prediction errors → Feature trust computed
6. Explanation: SHAP values generated → Suspicious features flagged
7. Output: Dashboard displays results → Model & report downloadable
📖 System Benefits
  • Data Quality Assessment: Quantifies trustworthiness across 5 dimensions
  • Intelligent Weighting: Unreliable rows contribute less to model training
  • Trust Propagation: Similar rows share trust through graph structure
  • Automated ML: Trains and compares 3 model families automatically
  • Explainability: SHAP values reveal which features drive predictions
  • Robustness: Noise simulation validates model stability
  • Transparency: Full visibility into reliability scores and trust metrics
